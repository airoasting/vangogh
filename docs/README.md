# 반 고흐 그림 지도 백과

초등학교 3학년이 세계 지도를 눌러 반 고흐 그림을 찾아가는 HTML 백과사전이다.

- 분류. Prototype (Content-to-System 축의 "아이용 인터랙티브 백과" 템플릿 실험)
- 목표 등급. 7점 (15분 안에 멀티 에이전트로 작동하는 첫 판)

## 사용법

`index.html`을 브라우저로 연다. 빌드 과정은 없다. 그림 이미지는 Wikimedia Commons에서 불러오므로 인터넷 연결이 필요하다.

1. 맨 위 30초 영상의 재생 버튼을 누르면 모션 그래픽과 음악(Web Audio로 합성)이 함께 나온다.
2. 지도에서 노란 핀(미술관)을 누르면 그 도시로 확대되고, 오른쪽에 그 미술관의 그림 갤러리가 열린다.
3. 마우스 휠, 두 손가락, ＋/－ 버튼으로 확대와 축소를 한다. "고흐가 살던 곳 보기"로 바꾸면 고흐가 살았던 도시를 순서대로 따라간다.

## 다른 화가로 재사용하는 법

`data.js`만 바꾸면 된다. 형식은 다음과 같다.

```js
window.VG_DATA = {
  museums: [{ id, nameKo, nameEn, city, country, flag, lat, lon, intro,
              works: [{ id, titleKo, titleEn, year, img, story, lookFor, fun }] }],
  life: [{ id, placeKo, country, lat, lon, years, story, emoji }],
  versions: [{ id, titleKo, lead, ask, works: [작품 id] }]  // 나란히 보기, 없어도 된다
}
```

인트로 영상은 `intro.js`의 장면 대본(자막 문구, 그리는 대상)을 바꾼다.

## 디자인

현재 기준: 미술관 웹사이트 수준의 편집 디자인, 글꼴은 Pretendard, AI스러운 장식(왼쪽 색 띠, 이모지 아이콘, 알약 배지, 그림자 카드, 그라데이션)은 쓰지 않는다. 지도는 처음에 글자를 보이지 않고, 크게 확대했을 때만 미술관 이름을 보인다. 인트로는 코드로 그린 목판화 필름(검정, 울트라마린, 크롬 옐로, 종이색 네 가지 잉크, 거친 칼자국, 인쇄 입자)이다.

(이전 기록)

처음에는 AI ROASTING UI 디자인 트렌드의 클레이모피즘으로 만들었다가, 너무 아기자기하다는 피드백을 받고 미술관 전시실 톤으로 바꿨다. 따뜻한 흰 벽, 먹색 글자, 명조 제목(Noto Serif KR), 금박 액자색 포인트, 밤 전시실 같은 어두운 지도다. 설명 문장은 초3 눈높이를 그대로 둔다. 테마는 `gallery.css` 한 파일이라 지우면 클레이 버전으로 돌아간다.

## 미술관 범위

Wikidata에서 반 고흐 유화 중 이미지가 있고 공공 미술관에 있는 작품을 모두 가져왔다(128곳, 650점). 큐레이션 32점은 아이용 이야기가 있고, 나머지는 "고흐가 1888년에 아를에서 그린 그림이에요"처럼 연도와 장소 사실로만 한 줄을 만든다. 제목 451개는 번역 에이전트 4명이 나눠 옮기고 1명이 용어를 맞췄다. 아이용 백과라 「The Brothel」 1점은 뺐다.

유화가 아닌 작품(소묘 75점, 수채화 47점, 판화 6점, 모두 128점)은 `tools/other_media.json`이 정본이다. Wikidata에서 작가 Q5582이고 종류가 소묘, 수채화, 판화 계열이며 이미지와 좌표 있는 소장처가 있는 작품을 받았고(`tools/other_media.rq`), 한국어 제목과 종류를 붙였다. 메트로폴리탄의 「요양원 복도」는 소장 번호 48.190.2가 같은 항목이 둘이라 하나만 넣었다. 기존 유화에 누드와 토르소 습작이 있어 같은 기준으로 「비너스 토르소상과 풍경」, 「누워 있는 여인 누드 습작」도 넣었다. 그래서 145곳, 778점이 되었고, 중복 1점과 제목 기준으로 뺀 2점을 덜어 지금은 145곳, 775점이다.

2,100점을 다 담지는 못한다. 고흐의 소묘는 1,000점이 넘지만 Wikidata에 작품별 항목이 있는 것은 200점 남짓이고, 개인 소장 작품은 지도에 찍을 곳이 없다. 더 넣으려면 반 고흐 미술관, 크뢸러뮐러 미술관의 소장품 목록처럼 다른 출처가 필요하다.

갱신: Wikidata 쿼리(SPARQL, 작가 Q5582, 유화 Q3305213, 소장처가 박물관이고 좌표가 있는 곳)를 다시 받아 `catalog.json`을 만들고 `python3 -I tools/build_catalog.py <작업폴더> .`를 돌린다. 그다음 `python3 -I tools/add_other_media.py .`로 소묘, 수채화, 판화를 다시 합친다(여러 번 돌려도 결과가 같다).

(이전 기록) 처음 판은 13곳, 32점이었다. 뉴욕은 MoMA, 메트로폴리탄, 구겐하임(탄하우저 컬렉션의 「생레미의 산」)을 넣었다. 휘트니 미술관은 미국 작가 작품만 모으는 곳이라 고흐 그림이 없어서 넣지 않았다. 구겐하임의 다른 고흐 그림 「고가 다리가 있는 길」(1887)은 확인된 퍼블릭 도메인 이미지를 찾지 못해 다음 갱신으로 미뤘다.
