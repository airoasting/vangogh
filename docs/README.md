# 반 고흐 그림 지도 백과

초등학교 3학년이 세계 지도를 눌러 반 고흐 그림을 찾아가는 HTML 백과사전이다.

- 분류. Prototype (Content-to-System 축의 "아이용 인터랙티브 백과" 템플릿 실험)
- 목표 등급. 7점 (15분 안에 멀티 에이전트로 작동하는 첫 판)

## 사용법

`index.html`을 브라우저로 연다. 빌드 과정은 없다. 그림 이미지는 Wikimedia Commons에서 불러오므로 인터넷 연결이 필요하다.

1. 맨 위 30초 영상의 재생 버튼을 누르면 모션 그래픽과 음악(Web Audio로 합성)이 함께 나온다.
2. 지도에서 노란 핀(미술관)을 누르면 그 도시로 확대되고, 오른쪽에 그 미술관의 그림 갤러리가 열린다.
3. 마우스 휠, 두 손가락, ＋/－ 버튼으로 확대와 축소를 한다. "고흐가 살던 곳 보기"로 바꾸면 고흐가 살았던 도시를 순서대로 따라간다.

## 다른 화가로 재사용하는 법

`data.js`만 바꾸면 된다. 형식은 다음과 같다.

```js
window.VG_DATA = {
  museums: [{ id, nameKo, nameEn, city, country, flag, lat, lon, intro,
              works: [{ id, titleKo, titleEn, year, img, story, lookFor, fun }] }],
  life: [{ id, placeKo, country, lat, lon, years, story, emoji }]
}
```

인트로 영상은 `intro.js`의 장면 대본(자막 문구, 그리는 대상)을 바꾼다.

## 디자인

현재 기준: 미술관 웹사이트 수준의 편집 디자인, 글꼴은 Pretendard, AI스러운 장식(왼쪽 색 띠, 이모지 아이콘, 알약 배지, 그림자 카드, 그라데이션)은 쓰지 않는다. 지도는 처음에 글자를 보이지 않고, 크게 확대했을 때만 미술관 이름을 보인다. 인트로는 코드로 그린 목판화 필름(검정, 울트라마린, 크롬 옐로, 종이색 네 가지 잉크, 거친 칼자국, 인쇄 입자)이다.

(이전 기록)

처음에는 AI ROASTING UI 디자인 트렌드의 클레이모피즘으로 만들었다가, 너무 아기자기하다는 피드백을 받고 미술관 전시실 톤으로 바꿨다. 따뜻한 흰 벽, 먹색 글자, 명조 제목(Noto Serif KR), 금박 액자색 포인트, 밤 전시실 같은 어두운 지도다. 설명 문장은 초3 눈높이를 그대로 둔다. 테마는 `gallery.css` 한 파일이라 지우면 클레이 버전으로 돌아간다.

## 미술관 범위

Wikidata에서 반 고흐 유화 중 이미지가 있고 공공 미술관에 있는 작품을 모두 가져왔다(128곳, 650점). 큐레이션 32점은 아이용 이야기가 있고, 나머지는 "고흐가 1888년에 아를에서 그린 그림이에요"처럼 연도와 장소 사실로만 한 줄을 만든다. 제목 451개는 번역 에이전트 4명이 나눠 옮기고 1명이 용어를 맞췄다. 아이용 백과라 「The Brothel」 1점은 뺐다.

갱신: Wikidata 쿼리(SPARQL, 작가 Q5582, 유화 Q3305213, 소장처가 박물관이고 좌표가 있는 곳)를 다시 받아 `catalog.json`을 만들고 `python3 -I tools/build_catalog.py <작업폴더> .`를 돌린다.

(이전 기록) 처음 판은 13곳, 32점이었다. 뉴욕은 MoMA, 메트로폴리탄, 구겐하임(탄하우저 컬렉션의 「생레미의 산」)을 넣었다. 휘트니 미술관은 미국 작가 작품만 모으는 곳이라 고흐 그림이 없어서 넣지 않았다. 구겐하임의 다른 고흐 그림 「고가 다리가 있는 길」(1887)은 확인된 퍼블릭 도메인 이미지를 찾지 못해 다음 갱신으로 미뤘다.

## 변경 기록

- 2026-10-31. 4인 비평(RED, SILVER, BLUE, GOLD) 1순위 반영. 이야기 있는 32점을 그림 벽과 미술관 패널 맨 앞에 두고 "이야기 있음" 표시와 "이야기 있는 그림" 필터를 넣었다. 그림 찾기 칸(제목, 미술관, 도시, 나라, 그린 곳)과 빠른 버튼(해바라기, 별이 빛나는 밤, 자화상, 일본)을 넣었다. 이야기가 없는 618점의 크게 보기에는 VTS 관찰 질문 두 개와 돌아가며 나오는 질문 하나를 붙였다(`app.js`의 `LOOK_EXTRA`). 크게 보기 화면에 "지도에서 이 미술관 보기"를 넣었다.
- 2026-10-31. "고흐가 살던 곳" 카드에 그곳에서 그린 그림을 이었다. "여기서 그린 그림 N점이 지금은 몇 나라, 몇 곳 미술관에 있어요" 한 줄, 그림 세 점(이야기 있는 그림 먼저), 모두 보기. 묶는 기준은 그림의 `place`가 생애 도시와 같고 연도가 살던 기간 안인 것이다(`app.js`의 `paintedAt`). 몽마르트르는 파리로, 생폴드모졸 수도원은 생레미로 본다. 살던 기간 밖 연도 6점(예: 1885년 「큰박쥐」가 파리로 잡힘)은 Wikidata 데이터 어긋남으로 보고 뺐다. 쥔더르트, 런던, 보리나주는 유화가 데이터에 없어 그림 줄을 붙이지 않는다.
- 같은 날. 큐레이션 4점에 그린 곳이 비어 있던 것을 정본 이야기 문장 기준으로 채웠다(`data.curated.js`의 `place`). `build_catalog.py`가 큐레이션의 `place`를 쓰도록 고쳤고, `catalog.json`이 없어 재빌드 대신 `data.js`의 같은 네 줄만 맞췄다. 「침실 (두 번째 그림)」은 이야기에 장소가 없어 비워 두었다.
- 같은 날. 지도 위에 찾기 문제 3개를 넣었다(「별이 빛나는 밤」 뉴욕, 「감자 먹는 사람들」 암스테르담, 「장미」 도쿄). 문제와 힌트(나라, 도시와 미술관)는 데이터에서 만들고, 그 미술관을 열면 정답이며 그림이 크게 열린다. 인트로 끝 버튼은 "지도에서 첫 문제 풀기"로 바꾸고 `vg:quest` 신호를 보낸다. 문제를 바꾸려면 `app.js`의 `QUESTS`에 작품 id만 넣는다.
- 같은 날. 살던 곳 카드에 나이 한 줄을 넣었다("20살부터 23살까지 살았어요"). 나이는 `years`에서 태어난 해 1853(`app.js`의 `VG_BIRTH`)을 뺀 값, 즉 그 해에 맞은 나이다. 태어난 해만 있으면 "갓 태어난 아기 때", 한 해만 있으면 "N살 때 이곳으로 왔어요"로 쓴다.
- 같은 날. 크게 보기에 "읽어 줘요" 버튼을 넣었다. 브라우저 내장 한국어 음성(speechSynthesis)으로 제목, 이야기, 찾아보기, 알고 있나요(이야기 없는 그림은 관찰 질문)를 읽는다. 크롬이 긴 글을 15초쯤에서 끊는 문제 때문에 문장 단위로 나눠 읽히고, 그림을 넘기거나 닫으면 멈춘다. 한국어 음성이 없는 기기에서는 버튼을 숨긴다. 오래된 iOS 사파리를 위해 정규식 lookbehind는 쓰지 않는다.
- 같은 날. 헤더 로고를 크롬 옐로 라벨로 바꾸고 AI 로스팅 로고(`assets/ai-roasting-logo.png`, 블로그 프로젝트의 logo1-transparent.png를 120px로 줄인 것)를 붙였다. 로고 글자에 마우스를 올리면 물결이 지나간다(움직임 줄이기 설정이면 끔). 폰에서는 AI ROASTING 글자를 숨기고 로고 그림만 둔다.
- 같은 날. 「귀에 붕대를 감은 자화상」(코톨드 갤러리)을 큐레이션에 더해 이야기 있는 그림이 33점이 되었다. 아이용 문장은 "마음이 아팠던 때 귀를 다쳐 치료를 받고 다시 그렸다"까지만 쓰고, 다친 경위와 날짜는 새 필드 `forAdults`(어른을 위한 메모, 접힌 칸, 읽어 줘요 제외)에 두었다. `build_catalog.py`가 `forAdults`를 옮기도록 고쳤고, `data.js`는 이 항목만 정본 값으로 맞췄다. 찾아보기(일본 판화)와 알고 있나요(거울 때문에 좌우가 바뀜)는 그림 이미지를 직접 보고 확인했다.
- 같은 날. 헤더 순서를 "AI ROASTING 로고 | 반 고흐 그림 지도"로 바꾸고, AI 로스팅 로고의 주황 원을 짙은 황금빛 노란 원으로 다시 칠했다(`tools/recolor_logo.py --deep=0.6`, 원본은 블로그 프로젝트의 logo1-transparent.png). 지도 아래에 "이 지도에는 아직 한국 미술관이 없어요" 한 줄을 넣었다. 서울에서 가장 가까운 미술관과 그 나라의 미술관 수, 그림 수는 데이터로 계산하고, "일본 지도에서 보기"는 이름표가 보이는 6.5배로 확대한다.
